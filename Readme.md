# Quiz App

A simple and intuitive quiz application built with **React Native** and **Expo**. This app allows users to test their knowledge with interactive quizzes.

## Features

- Interactive multiple-choice quizzes.
- Timer-based questions.
- Score tracking.
- User-friendly interface.

## Tech Stack

- **React Native**: For building the mobile app.
- **Expo**: For simplified development and deployment.

## Dependencies

- **React Native**
- **Expo**
- Expo Router (for navigation)
